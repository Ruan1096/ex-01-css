We Care - Pet Care Landing Page
💻 Sobre o Projeto
Este projeto consiste no desenvolvimento de uma Landing Page institucional para a marca "We Care", especializada no setor de cuidados com animais de estimação. O objetivo principal foi criar uma interface moderna, minimalista e intuitiva, priorizando a experiência do usuário (UX) e a hierarquia visual clara.

A página apresenta uma proposta de valor direta, utilizando elementos gráficos de alta qualidade e chamadas para ação (CTAs) estrategicamente posicionadas para conversão de usuários.

🛠 Tecnologias e Conceitos Aplicados
HTML5 Semântico: Utilização de tags estruturais (header, main, section) para garantir melhor acessibilidade e indexação por motores de busca (SEO).

CSS3 Custom Properties: Implementação de estilos modernos, com foco em:

Tipografia Avançada: Integração com Google Fonts (Montserrat) para garantir uma identidade visual consistente.

Box Model & Layout: Controle preciso de margens, preenchimentos e dimensões para harmonia visual.

UI Elements: Botões com efeitos de drop-shadow e estados de interação.

Design Minimalista: Paleta de cores contrastante para destacar pontos de conversão, utilizando tons de cinza para leitura confortável e cores vibrantes (#adff00) para ações principais.

📑 Estrutura de Arquivos
index.html: Estrutura de conteúdo e links de navegação.

style.css: Folha de estilo contendo toda a lógica visual, resets de margens e estilização de componentes.
